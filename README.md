# Kampala Business Hub 🇺🇬

Kampala Business Hub is a modern, responsive business website designed to demonstrate how businesses can use technology to improve their online presence and connect with customers.

The project was built using **HTML, CSS, and JavaScript** with a focus on clean design, responsiveness, and interactive features.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern navigation bar
- Hero section with call-to-action buttons
- Services section
- Business statistics section
- About section
- Customer testimonials
- Contact form
- Dark mode / light mode
- Mobile navigation menu
- Interactive form validation
- Smooth scrolling
- Professional footer with social links

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, animations, and responsiveness
- **JavaScript** – Interactivity and functionality
- **Git & GitHub** – Version control and project hosting

## 💻 How to Run the Project

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional software or database is required to run the current version.

## 📱 Responsive Design

The website is designed to work on:

- 💻 Desktop computers
- 💻 Laptops
- 📱 Mobile phones
- 📟 Tablets

The layout automatically adjusts to different screen sizes using CSS media queries.

## 🌙 Dark Mode

The website includes a dark mode feature built with JavaScript. Users can switch between light and dark themes using the theme button in the navigation bar.

## 📩 Contact Form

The contact form allows users to enter:

- Name
- Email
- Subject
- Message

JavaScript is used to handle the form submission and display a confirmation message.

> Note: The current contact form is a front-end demonstration and does not yet send data to a real database or email server.
